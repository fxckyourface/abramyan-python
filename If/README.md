# If

10 самостоятельных решений. Каждое значение вводится с новой строки в указанном порядке.

| Задача | Что вычисляется / проверяется | Порядок ввода |
|---|---|---|
| [If1](if01.py) | Увеличение положительного числа на 1 | `n` |
| [If2](if02.py) | Положительное увеличить на 1, иначе уменьшить на 2 | `n` |
| [If3](if03.py) | Три случая: положительное, отрицательное, ноль | `n` |
| [If4](if04.py) | Количество положительных чисел | `a b c` |
| [If5](if05.py) | Количество положительных и отрицательных чисел | `a b c` |
| [If6](if06.py) | Большее из двух чисел | `a b` |
| [If7](if07.py) | Порядковый номер меньшего числа | `a b` |
| [If8](if08.py) | Сначала большее, затем меньшее число | `a b` |
| [If9](if09.py) | Меньшее значение в A, большее в B | `a b` |
| [If10](if10.py) | Замена переменных суммой или нулями | `a b` |

В If7 случай равных чисел в условии не уточнен: принято выводить `1`.
