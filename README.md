## Запуск

Откройте терминал в папке репозитория и запустите нужный файл:

```bash
python3 Begin/begin03.py
```

На Windows вместо `python3` можно использовать `python` или `py`.
Каждое исходное значение вводится **с новой строки**, в порядке из комментария в начале программы или таблицы раздела. Для дробной части используется точка.

Например, для Begin3 введите:

```text
3
4
```

Результат — площадь и периметр прямоугольника:

```text
12.0 14.0
```

Если ответов несколько, они выводятся в порядке условия, разделенные пробелами; в Begin27 и Begin28 степени выводятся по одной на строку. Логические задачи выводят `True` или `False`.

## Принятые условия

- Входные данные соответствуют ограничениям задачника; отдельная проверка некорректного ввода не добавлена.
- В Begin используется `pi = 3.14`, как указано в условиях.
- Цифры целых чисел выделяются через `//` (целая часть частного) и `%` (остаток).
- В Begin27 и Begin28 соблюдено ограничение на количество умножений и вспомогательных переменных.
- В If7 при равных числах выводится `1`; этот случай в условии отдельно не определен.
- Вещественные результаты не округляются принудительно; возможна обычная для `float` погрешность.
